MON APPROCHE

Construire, observer,
faire évoluer.

Je développe ces projets avec assistance IA, en reliant l’usage attendu aux règles de fonctionnement, à l’interface et aux vérifications.

01 / CONCEVOIR

Partir d’un usage

Définir les interactions, les informations nécessaires et les décisions que l’utilisateur doit pouvoir prendre.

02 / DÉVELOPPER

Relier les composants

Construire l’interface, les données et les traitements. Intégrer les API quand elles apportent une fonction utile.

03 / VÉRIFIER

Tester le fonctionnement

Examiner les résultats, les accès, les cas limites et les reprises après erreur, dans le contexte de chaque application.

04 / AMÉLIORER

Itérer sur du concret

Observer les interactions, conserver les données et faire évoluer le produit à partir des essais et des retours.

Le démonstrateur IA se prête aussi à une lecture du code.Son dépôt public rassemble l’API, le workflow, les tests, les fichiers de déploiement et le compte rendu de l’essai Azure.
