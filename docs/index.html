03 / EXTENSION CHROME

MyConf

Traiter le son dans le navigateur et afficher des sous-titres pour un usage en conférence.

J’ai développé le traitement audio de l’extension et son interface de sous-titrage. Le traitement du signal s’exécute dans un AudioWorklet et prépare des blocs PCM pour le relais.

  • JavaScript
  • Web Audio
  • AudioWorklet
Ce que j’ai testé

Les essais locaux ont comparé le PCM16 à 48 kHz et la continuité aux jonctions entre les blocs. Ils portent sur le prototype Chrome. La diffusion sur téléphone et réseau de conférence reste à valider.
